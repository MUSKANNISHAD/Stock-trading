# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone participating in this project, regardless of experience level, background, identity, or viewpoint.

## Expected Behavior

- Be respectful, considerate, and constructive.
- Give and accept feedback gracefully.
- Focus criticism on ideas and code, not people.
- Use inclusive language and respect differing perspectives.
- Help keep discussions relevant and welcoming to newcomers.

## Unacceptable Behavior

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, sexualized language or attention, trolling, and publishing another person's private information without permission. Disruptive or abusive conduct in project spaces is also not acceptable.

## Scope

This Code of Conduct applies in project spaces, including GitHub issues, pull requests, discussions, code reviews, and other spaces where someone is representing or participating in the project.

## Reporting

If you experience or witness unacceptable behavior, contact the repository maintainer, [Muskan Kumari Nishad](https://github.com/MUSKANNISHAD), privately using a contact method made available on their GitHub profile. Please include relevant links or context where possible. Do not post sensitive personal information in public issues.

## Handling Reports

The maintainer is responsible for reviewing reports, respecting the reporter's privacy as far as practical, and deciding on an appropriate response based on the circumstances. Possible responses include a warning, removal of content, or restriction from project spaces. No response time is guaranteed.
