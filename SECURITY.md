# Security Policy

## Supported Versions

This repository is an educational stock-trading simulation. Security fixes are considered for the current version on the default branch. No separate release support schedule is currently published.

## Reporting a Vulnerability

**Please do not report security vulnerabilities in public GitHub issues, pull requests, or discussions.**

Use GitHub's private vulnerability reporting channel for the upstream repository:

1. Open the [upstream repository's Security page](https://github.com/MUSKANNISHAD/Stock-trading/security).
2. If **Report a vulnerability** is available, use it to submit a private report.
3. Include a clear description, affected files or components, reproduction steps, potential impact, and any suggested mitigation. Avoid including real credentials or other people's personal data.

Private vulnerability reporting must be enabled by the upstream repository's maintainers. If the option is unavailable, do not disclose technical details publicly. Contact the maintainer through their [GitHub profile](https://github.com/MUSKANNISHAD) and ask for a private reporting channel before sharing the vulnerability details.

## What to Expect

The maintainers can review the report, request additional information, and determine next steps. This repository does not currently publish a guaranteed acknowledgement or remediation timeline. Please allow maintainers reasonable time to investigate and coordinate a fix before any public disclosure.

## Scope

Report vulnerabilities that could affect the confidentiality, integrity, or availability of this application or its users. This policy does not authorize accessing accounts, data, or systems that do not belong to you.
